# Minimum Number of Coins to be Added
#### _Description_
You are given a 0-indexed array `coins` (values of coins available, duplicates allowed) and an integer `target`. An integer amount `x` is *obtainable* if some subsequence of coins sums to `x`. Return the minimum number of coins of any value you need to add to the array so that every integer in the range `[1, target]` is obtainable.
