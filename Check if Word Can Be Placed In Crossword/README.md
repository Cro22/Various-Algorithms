# Check if Word Can Be Placed In Crossword
#### _Description_
You are given an `m x n` matrix `board`, representing the current state of a crossword puzzle, and a string `word`. Cells contain a lowercase letter (already placed), `' '` (empty) or `'#'` (blocked). A word can be placed horizontally (left to right) or vertically (top to bottom) if it fits entirely inside consecutive empty/matching cells bounded by the edge of the board or a `'#'` cell, and every letter matches the pre-placed letters. Return `true` if `word` can be placed, otherwise `false`.
