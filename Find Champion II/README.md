# Find Champion II
#### _Description_
There are `n` teams numbered from `0` to `n - 1` in a tournament, modelled as a directed acyclic graph. A directed edge `[u, v]` means team `u` is stronger than team `v`. A team is the *champion* if no other team is stronger than it. Return the champion (the unique team with in-degree `0`), or `-1` if there is no single champion.
