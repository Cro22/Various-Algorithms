# Maximum Non Negative Product in a Matrix
#### _Description_
You are given an `m x n` matrix `grid`. Starting at the top-left cell `(0, 0)`, you may only move right or down, ending at the bottom-right cell `(m - 1, n - 1)`. Among all paths, find the one with the maximum non-negative product of its cells. Return that maximum product **modulo** `10^9 + 7`. If the maximum product is negative, return `-1`. Because the product may be very large, the intermediate computation uses `BigInt`.
