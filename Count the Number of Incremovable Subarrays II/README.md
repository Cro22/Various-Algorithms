# Count the Number of Incremovable Subarrays II
#### _Description_
You are given a 0-indexed array of positive integers `nums`. A subarray is *incremovable* if removing it makes `nums` strictly increasing (the empty array counts as strictly increasing). Return the total number of incremovable subarrays of `nums`. Note that a subarray is a contiguous, non-empty sequence of elements.
