# Various-Algorithms

A personal collection of algorithm and coding-challenge solutions gathered from different
coding tests and practice problems. All programming languages are welcome.

## Repository structure

Every problem lives in its own folder that contains:

- a `README.md` describing the problem, and
- one subfolder per language (e.g. `JS/`) holding the solution file.

```
Problem Name/
├── README.md          # problem description
└── JS/
    └── Problem Name.js # solution
```
