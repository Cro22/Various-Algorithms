# Contributing

Thanks for taking the time to contribute! Please follow these guidelines so the
repository stays consistent and easy to browse.

## Guidelines

- **Any programming language is welcome.** If a language subfolder does not exist yet
  inside the problem folder, create it (e.g. `JS/`, `Python/`, `Java/`).
- **Every algorithm must have its own folder** named after the problem, containing a
  `README.md` that explains the problem.
- **Solutions go inside a language subfolder**, following this layout:

  ```
  Problem Name/
  ├── README.md
  └── JS/
      └── Problem Name.js
  ```

- **Test cases are allowed**, but only for the person who provides the algorithm.
- **Algorithms that fail their test cases will be removed** unless a working solution
  is provided.

## Naming

- Use the full, human-readable problem name for folders (e.g.
  `Rank Transform of an Array`, not `RankTransformArray`).
- Name the solution file after the problem inside its language folder.
